# 🎮 AFK Tracking Bot (Minecraft Fabric 1.21.11)

Кастомный клиентский мод для Minecraft, который позволяет удалённо отслеживать состояние вашего персонажа через Telegram-бота. Идеально подходит для AFK-фарма или просто для контроля, пока вы отошли от компьютера.

## 🚀 Возможности

* **Сохранение конфигурации:** Токен бота и ваш Chat ID сохраняются в файл `config/afk_tracking.txt`. При перезаходе в игру вводить их заново не нужно.
* **Управление из игры (с обратным слэшем `\`):**
  * `\tg_setup <token> <chat_id>` — привязка Telegram-бота.
  * `\tg_status` — отправить текущий статус (ХП, голод, опыт, координаты).
  * `\tg_inv` — отправить содержимое инвентаря.
  * `\tg_spam on` / `\tg_spam off` — включить/выключить авто-отчет каждые 5 минут.
* **Управление из Telegram (через бота):**
  * `/status` — получить статус.
  * `/inv` — получить инвентарь.
  * `/screen` — сделать и отправить скриншот экрана.
  * `/spam on` / `/spam off` — управление авто-отчетом удаленно.
* **Поддержка прокси:** Встроенная поддержка локального HTTP-прокси (Hiddify / WARP) для обхода блокировок Telegram.

## ⚙️ Установка

1. Установите [Fabric Loader](https://fabricmc.net/) для Minecraft **1.21.11**.
2. Скачайте последнюю версию [Fabric API](https://modrinth.com/mod/fabric-api) и положите в папку `mods`.
3. Скачайте `.jar` файл этого мода из раздела **Releases** и положите его в папку `mods`.
4. Запустите игру и введите токен в чате: `\tg_setup ТОКЕН ID`.

## ⚠️ Важное примечание
Мод использует локальный HTTP-прокси для отправки запросов. По умолчанию в коде стоит порт `12334` (для Hiddify). Если вы используете другой ВПН (например, WARP), измените переменную `PROXY_PORT` в файлах `TelegramSender.java` и `TelegramListener.java` перед сборкой.
